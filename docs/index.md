Add an AI chatbot to your WordPress site in minutes.

## Quick Start

1. **Install** → Upload the plugin to WordPress
2. **Configure** → Add your OpenAI API key
3. **Add** → Use `[praisonai_chat]` shortcode

That's it! 🎉
